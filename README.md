# Renan Marques — Engineering Portfolio

Portfólio profissional de **Renan Marques Fontana**, Senior Software Engineer com foco em performance, escalabilidade, observabilidade e IA aplicada.

## Stack do site

- Next.js 16
- React 19
- TypeScript
- CSS responsivo sem dependências de UI
- App Router

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Build de produção

```bash
npm run build
npm start
```

## Deploy na Vercel

1. Importe este repositório na Vercel.
2. Framework preset: **Next.js**.
3. Build command: `next build` (detectado automaticamente).
4. Não há variáveis de ambiente obrigatórias nesta versão.
5. Faça o deploy e depois associe um domínio próprio, se desejar.

## Conteúdo

A home apresenta posicionamento profissional, impacto, experiência e stack. Os estudos de caso aprofundam:

- IA + Grafana/Tempo para diagnóstico de produção;
- arquitetura multiagente para software delivery com gates humanos;
- performance, escalabilidade e modernização de legado.

Casos profissionais são descritos de forma anonimizada para evitar exposição de código, endpoints, clientes ou arquitetura confidencial.
